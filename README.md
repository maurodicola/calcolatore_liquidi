# Atelier Liquidi · Calcolatore personale

Un piccolo strumento web per calcolare la miscela di liquidi per sigarette elettroniche, con focus su:
- volume finale
- nicotina desiderata
- percentuale VG/PG
- dose dell’aroma
- scelta delle basette
- stampa delle etichette

Questo progetto è pensato come strumento personale e educativo, da usare in modo responsabile e conforme alle leggi del proprio Paese.

### Salute
La nicotina è una sostanza attiva e, in alcune condizioni, può essere tossica e altamente irritante. È fondamentale:
- usare guanti e protezioni adeguate
- lavorare in ambienti ben ventilati
- conservare i materiali in contenitori ben etichettati
- tenere il tutto lontano da bambini e animali domestici
- non usare il calcolatore senza avere le competenze necessarie per la manipolazione dei materiali

## ✅ Obiettivo del progetto

L’obiettivo è semplice:
- aiutare a calcolare la ricetta di una miscela in modo rapido e chiaro
- ridurre errori nelle proporzioni
- mantenere un archivio personale di ricette sul browser
- generare etichette stampabili per la preparazione

## 🧩 Funzioni principali

- impostazione del volume finale
- scelta della nicotina finale in mg/ml
- definizione percentuale VG/PG
- impostazione della percentuale aroma
- scelta delle basette di partenza
- calcolo delle dosi di:
  - VG
  - PG
  - basette
  - aroma
- salva e gestione ricette personali nel browser
- esportazione in JSON o CSV e importazione da JSON
- archivio su file (Chrome ed Edge sul computer): le ricette si salvano anche in un file .json, per esempio in Documenti
- stampa di etichette

## 📦 Requisiti

Questo progetto è in HTML, CSS e JavaScript puro.

Per usarlo:
- un browser moderno
- nessuna dipendenza esterna
- nessun backend richiesto

## ▶️ Come usare

1. Aprire il file HTML direttamente nel browser
2. Inserire:
   - volume finale
   - nicotina desiderata
   - composizione VG/PG
   - percentuale aroma
   - basette disponibili
3. Verificare i valori calcolati
4. Salvare la ricetta se necessario
5. Stampare etichette, se utile
